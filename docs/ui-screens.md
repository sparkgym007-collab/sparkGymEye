# SPARK GymEye Screens

## Admin Dashboard

- Member count
- Overdue count
- Total outstanding amount
- Today's attendance
- Quick actions for adding members and marking attendance

## Trainer Attendance

- Search member by name, roll number, or phone.
- Mark today's check-in.
- View live list of checked-in members.

## Fees Monitor

- View overdue members.
- View due-soon members.
- Filter by plan duration.
- Export overdue list to Excel.

## Member Portal

- Membership validity.
- Last payment.
- Attendance history.
- Next due date.

## Reports & Automation

- Weekly report status.
- Report day and time.
- Recipient email and CC.
- Last generated report.
- Manual "Generate Now" action.
- WhatsApp notification toggle for a later provider integration.
